# Saksham Gupta Design

Create a **simple, fast, professional one-page portfolio website for Saksham Gupta**, an entry-level Interior Design professional.

The website is only for recruiters to quickly view his **profile, interior design projects, certificates, and contact details**.

Do NOT create:

* Login
* Admin dashboard
* Database
* CMS
* Backend
* Authentication
* Complex animations
* AI features
* Booking system
* Blog
* Testimonials
* Pricing
* Unnecessary sections

Keep everything **static, lightweight and easy to edit**.

## DESIGN

Make it look like a premium **Interior Design / Architecture portfolio**.

Style:

* Minimal
* Modern
* Professional
* Architectural
* Elegant
* Warm neutral colors
* White/off-white background
* Dark typography
* Large project images
* Plenty of whitespace

The website should feel like a **designer's portfolio**, not a generic resume website.
